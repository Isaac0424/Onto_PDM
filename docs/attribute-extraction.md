# 속성 추출

CAD · 사양서 · BOM 시트에서 부품 속성 **후보**를 뽑는 규칙이다. 코드: [web/src/extract/](../web/src/extract/) (순수 함수, 화면 · 서버 어디서든 쓴다). PRD 11장의 "지금 되는 것"을 구현한 것이다.

## 원칙

- **원문에 없는 값은 채우지 않는다** (OPMS 와 같다). 이름에 규격이 없으면 규격 속성을 만들지 않고, 크기를 모르면 치수를 만들지 않는다.
- 뽑은 값은 **후보**(`ExtractedAttribute`)다: `source`(cad · name · spec · bom), `evidence`(근거), `confidence`(0~1), 추정이면 `estimated: true`. 부품 속성은 **사람이 확정해야** 된다.
- 단위는 OPMS 기준 단위로 환산하고(길이 mm, 토크 N·m, 질량 kg), 환산했으면 evidence 에 원값을 남긴다.

## 무엇을 어디서 뽑나

### CAD 형상 (`extractCadAttributes`, source `cad`)

| 속성 | 근거 | 신뢰도 |
|---|---|---|
| `length` · `width` · `height` | 크기(x · y · z)를 큰 순으로 | 0.90 |
| `thickness` | 가장 얇은 치수 | 0.85 |
| `volume` | 닫힌 메시에서 계산 / 열린 메시는 추정 | 0.80 / 0.40 (`estimated`) |

inch · cm 는 mm 로 환산한다. 단위를 모르거나 크기에 0 이하가 있으면 만들지 않는다. 크기는 축에 맞춘 상자라서, 비스듬히 놓인 부품은 실제보다 크게 나올 수 있다.

### 부품 이름의 규격 표기 (source `name`)

| 이름 | 속성 | 신뢰도 |
|---|---|---|
| `M3` · `M3x8` · `M3×12` | `threadSize` = M3, `length` = 8 mm | 0.90 / 0.85 |
| `Φ10` · `φ10` | `diameter` = 10 mm | 0.90 |
| `400W` · `2.2kW` | `ratedPower` | 0.85 |
| `48V` | `ratedVoltage` | 0.80 |
| `3mm` | `nominalSize` (표기 치수) | 0.60 |
| `3 kg` · `120g` | `mass` (kg). 정격 · 가반하중일 수 있어 낮게 | 0.50 |
| `D10` | `diameter`, 코드와 헷갈릴 수 있어 `estimated` | 0.50 |

같은 글자를 두 규칙이 읽지 않는다(`M3x8mm` 의 8 이 표기 치수로 또 나오지 않는다).

### 사양서 본문 (`extractSpecAttributes`, source `spec`)

본문을 문장으로 나누고, **부품 이름이 나오는 문장**과 그 **앞뒤 한 문장**에서만 찾는다. 이름 전체가 나오거나 의미 있는 토큰이 모두 나와야 그 부품 이야기로 본다(`기판 나사 M3` 는 "기판"과 "나사"가 둘 다 있어야 한다). 이웃 문장이 함께 주어진 다른 부품 이야기면 쓰지 않는다.

| 속성 | 읽는 표기 | 신뢰도 |
|---|---|---|
| `torque` | `0.6 N·m`, `0.6Nm`, `N-m`, `N·cm`, `6 kgf·cm` (N·m 로 환산) | 0.85 |
| `torqueTolerance` | 같은 문장의 `±10%` (토크가 있을 때만) | 0.80 |
| `material` | SUS304 / STS304 / AISI 304 / 1.4301 → `SUS304`, SS400, A6061, SCM435 … | 0.85 |
| `thickness` · `length` · `diameter` | `두께 3mm`, `길이 12 mm`, `지름 Φ8` (단위 없으면 mm 로 읽고 낮게) | 0.80 / 0.60 |
| `threadSize` · `length` | `M3` ~ `M24`, `M3x8` | 0.80 / 0.70 |
| `ratedVoltage` · `ratedCurrent` · `ratedPower` | `12V`, `50mA`, `400W` | 0.75 |

- 이웃 문장에서 찾은 값은 신뢰도를 0.3 낮춘다.
- 같은 속성 · 같은 값이 여러 구절에 있으면 **가장 가까운 구절 하나**만 둔다.
- 같은 속성에 **다른 값**이 있으면(예: 토크 0.6 / 0.8) 둘 다 후보로 두고 신뢰도를 ×0.6 으로 낮추며, evidence 에 "확인이 필요함"을 붙인다.
- evidence 는 원문 문장 그대로이고, 120자가 넘으면 값 주변만 남긴다.

### BOM 시트 (`parseBomSheet`, `matchBomSheet`)

- **읽기**: csv · tsv · 세미콜론 구분 자동 감지, 따옴표 · 따옴표 안의 쉼표와 줄바꿈 · `""` · CRLF · UTF-8 BOM. 머리줄에서 열을 찾는다(품번/Part No/Item No/P/N, 품명/이름/Name/Description, 수량/Qty/EA, 도면번호/Find No). 머리줄이 없으면 (품번, 이름, 수량) 순서로 읽고 알린다. **수량 열이 없으면 수량을 지어내지 않고 모두 건너뛴다.**
- **건너뛰는 줄**: 수량이 숫자가 아니거나 0 이하(`1,5` 는 따옴표 안에서만 소수), 품번과 이름이 모두 빈 줄. 이유는 `warnings` 에 "줄 N: …"으로 남는다. 줄 번호는 머리줄과 빈 줄을 세지 않는다. 같은 품번이 겹치면 알리되 합치지 않는다.
- **맞추기**: 품번 일치(대소문자 · 하이픈 · 공백 무시) = `matched`(확정, 이름이 다르면 사유에 알림). 품번이 없거나 못 찾았을 때 이름이 정확히 일치하거나 유사도 0.6 이상이면 `suggested`(후보, 품번 확인 필요). 아니면 `none`(등록 요청 대상).

## 안 하는 것

| 하지 않는 것 | 이유 · 대안 |
|---|---|
| 재료 · 표면처리 · 공차 · 용접 기호 · 나사 피치를 CAD 에서 읽기 | 대부분의 STEP 에 없다(AP242 제품 제조정보가 있어야 한다). 없으면 사양서 · 도면에서 와야 한다 |
| PDF 표 · 스캔본 | 표는 글자 위치가 깨지고 스캔본은 글자 인식(OCR)이 필요하다. 지금은 **텍스트(txt · md)만** 읽는다 |
| xlsx | 라이브러리가 필요하다. csv 로 내려받아 올린다 |
| 사양서 문장의 의미 이해(부정문 · 개정 전/후 판단) | 이름 근처의 패턴만 본다. 충돌은 사람에게 넘긴다 |
| STL · OBJ · GLB 의 이름 · 계층 | 단일 메시라 치수만 가능하다 |

알려진 한계: 이름이 다른 부품 이름의 일부일 때("기판" / "제어 기판") 문장 소속을 못 가릴 수 있다. 하나의 부품 이름만 주면 이웃 문장이 다른 부품 이야기인지 알 수 없어 낮은 신뢰도로 후보에 오른다.

## 사람이 확정하는 흐름

1. 파일을 올린다 → 추출이 후보를 만든다 (CAD · 이름은 즉시, 사양서는 본문을 읽을 때).
2. 화면이 후보를 근거 · 신뢰도와 함께 보인다. 신뢰도가 낮거나 `estimated` 이거나 충돌하는 값은 눈에 띄게 한다.
3. 사람이 **확정** 또는 **제외**한다. 확정한 값만 부품 속성이 되어 조립 규칙(두께로 나사 길이 계산 등)과 OPMS 등록 요청에 쓰인다.

## 예시

```
extractCadAttributes([{ name: '상부 커버 M3x12', size: [3, 126, 80] }])
→ length 126 mm (cad, 0.90)   width 80 mm   height 3 mm
  thickness 3 mm (cad, 0.85, "가장 얇은 치수 = 3 mm")
  threadSize "M3" (name, 0.90, '이름 "상부 커버 M3x12"의 "M3x12"')   length 12 mm (name, 0.85)

extractSpecAttributes('기판 나사 M3의 체결 토크는 0.6 N·m ±10% 이다.', ['기판 나사 M3'])
→ torque 0.6 N·m (spec, 0.85)   torqueTolerance 10 % (0.80)   threadSize "M3" (0.80)
  evidence = 원문 문장 그대로

parseBomSheet('품번,품명,수량\nP-1,볼트,4\nP-2,너트,abc')
→ rows [{ line: 1, itemNo: 'P-1', name: '볼트', quantity: 4 }]
  warnings ['줄 2: 수량이 숫자가 아닙니다 ("abc") — 건너뜁니다']
```
