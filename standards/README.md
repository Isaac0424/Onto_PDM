# 표준 사전 원본 (git에 올리지 않음)

ECLASS · IEC CDD 원본 파일은 라이선스 때문에 이 폴더에만 두고 git에는 올리지 않는다(`.gitignore`).
저장소에는 우리 분류 · 속성에 붙인 **IRDI(식별자)** 만 들어간다 (`ontology/*.ttl`의 `opdm:standardIrdi` · `opdm:unitIrdi`).

```
standards/
  eclass/     ECLASS 다운로드 (압축 파일 그대로)
  iec-cdd/    IEC CDD에서 직접 확인한 메모가 있으면 여기에
```

## ECLASS 무료판 받기 (Asset 판)

계정 생성과 라이선스 동의가 필요해서 직접 받아야 한다.

1. [ECLASS 상점](https://eclass.eu/shop/en/product/eclass-16-0-asset)에 회원가입하고 로그인한다. 회사 메일을 쓴다.
2. **My profile**에서 할인 코드 `asset-158`을 입력한다. 상점 페이지에 공개된 무료 활성화 코드다.
3. 개인 다운로드 영역에서 **ECLASS 16.0 (Asset)** 을 받는다. 영어 · 독일어만 있고, 범위는 정식판보다 좁을 수 있다.
4. 받은 파일을 압축 그대로 `standards/eclass/`에 둔다.
5. 파일이 들어오면 형식을 확인해 두 가지를 만든다.
   - **변환**: ECLASS 분류 → 우리 분류 후보(SKOS / OWL)
   - **커버리지 리포트**: 우리 부품 목록이 ECLASS에 얼마나 덮이는지

정식판(16.0, €700부터, 31개 언어, Basic CSV · XML / Advanced XML)은 커버리지를 보고 나서 정한다.

## IEC CDD 무료 범위에서 쓰기

- **열람**: [cdd.iec.ch](https://cdd.iec.ch)를 브라우저로 본다. 무료이고 로그인이 필요하다.
  - 사이트가 자동 수집을 막고 접속을 기록하므로, 스크립트로 내려받지 않는다.
- **자유롭게 쓸 수 있는 것**: 사용권 계약의 "free attributes"뿐이다. 식별자(IRDI) · 버전 · 개정 · 이름 같은 항목으로, 대응 · 데이터 교환 용도다.
  - 정의 문장 · 값 목록 같은 나머지 내용은 IEC 저작권이다. 참고만 하고 복사하지 않는다.
  - 정확한 조항은 사이트의 사용권 계약에서 확인한다.
- **기록 방법**: 우리 분류 · 속성에 IRDI만 단다. 예: `cls:C0400 opdm:standardIrdi "0112/2///61360_4#…"`
- **단위**: IEC 62720 단위 IRDI는 QUDT(CC BY 4.0)의 `qudt:iec61360Code`에서 가져온다. CDD에 직접 접속하지 않는다.
  - 예: kg = `0112/2///62720#UAA594`, g/cm³ = `0112/2///62720#UAA469`
- **먼저 볼 대상**: 전기 · 전자 부품 (모터, 엔코더, 센서, 커넥터, 케이블, 전원 · 제어 보드 부품)
